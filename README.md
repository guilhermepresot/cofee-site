# ☕ Cofee

Site de uma cafeteria fictícia desenvolvido como projeto de aprendizado de HTML e CSS.

## 📄 Páginas

- **Home** — apresentação e destaques do cardápio
- **Cardápio** — lista completa de bebidas com fotos e preços
- **Sobre** — história, valores e localização da cafeteria

## 🛠️ Tecnologias

- HTML5
- CSS3
